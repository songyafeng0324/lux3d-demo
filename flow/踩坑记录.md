## 2026-11-06 · 场景有阴影开关仍可能看不到投影 [已解决]

- 初版小屋补光过强且没有投影。藏宝阁只有屋顶外方向光投影，入口处效果极弱。浏览器里应核对投影实际落在家具、展台、地板上。
- 本机同机位比较使用光源阴影强度开关。仅切渲染器的阴影开关会遇到已缓存材质程序，可能拍到两张相同画面。复验含摆放后投影轮廓变化。

## 2026-11-06 · 在小屋内登录时保留过期会话的草稿 [已解决]

- 首轮实现把被动 401 当成切换账号，账号抽屉加载时会清掉未保存布局。GPT-6 Astra 独立评审发现该路径。
- 被动 401 只暂停写入，保留原作者、草稿和待确认的请求；原账号重新登录后换用新 CSRF，用户可按同一个 key 和 body 重试。明确退出或换账号才销毁旧保存控制器。
- 已在 Mac Chrome 复现 401，验证同账号重登后的原请求回放，复审关闭该项。

## 2026-11-06 · 旧背包回归命中两个简介字段 [已解决]

- **现象**：T08 新增投稿表单后，T06 Chrome 回归的“简介”定位同时命中个人编辑与公共投稿。
- **解决**：在有“保存资料”按钮的表单内定位名称和简介，复验受控 UI 通过。
- **另一个缺口**：PRD 要求手机显示电脑操作提示，现已在首页入口与小屋界面补齐；Chrome 触屏模拟通过。

## 2026-11-05 · 云端容器只能用软件WebGL，帧耗时0.5～2.7秒 [已绕开]
- **现象**：Playwright Chromium在1440×900下每帧约2.7s，点击动作超时；640×400仍约0.85s。带`--use-angle=swiftshader`时rAF显示17ms，但画面未必真实呈现，不能当性能数据。
- **触发条件**：云端Linux容器无GPU，ANGLE走SwiftShader；项目node_modules是darwin-arm64，Mac侧依赖不能在Linux VM执行。
- **解决**：导航按帧率无关设计并单测覆盖4FPS；容器内以640×400跑真实键盘全流程，脚本按实测帧时调整到达半径与等待；性能结论只在用户M5/Chrome上测（`npm run test:t10`）。
- **教训**：容器帧率不代表目标设备，证据里必须写明渲染器与视口。

## 2026-11-05 · 远程挂载目录中git残留index.lock [已解决]
- **现象**：`git commit`报`.git/index.lock: File exists`。
- **触发条件**：通过Claude桌面端挂载的文件夹默认禁止删除，git无法删除自身锁文件。
- **根因**：此前一次git命令创建锁后删除失败，留下0字节锁。
- **解决**：确认锁为刚产生的空文件且无其他git进程后，获用户删除授权，删除锁再提交。
- **教训**：在挂载目录用git前先取得删除授权；出现锁先看时间戳再删。

## 2026-11-04 · T04旧回执、在途拒绝与预览回收 [已解决]
- **现象**：保存ACK重apply布局使暂停中的拖动回弹；422到达前新草稿仍重发旧pending；会话重启后旧cap反复403；仅主renderer计数不能证明独立预览回收。
- **处理**：同引用跳过apply且保护拖动中实例；确定拒绝清pending并续最新草稿；EDITOR_REQUIRED续会话后原key/body重试一次；详情与场景销毁实际forceContextLoss，并记录CDP GC数据。
- **验证**：真实鼠标/网络门控回归、12次详情关闭/3次场景重建、23项单元/API及独立复审通过，见场景验证与T04评审。
- **补充**：基础worker停止后旧心跳在10秒有效窗内，立即运行缺worker冒烟可能得到200；窗口过后重跑PASS，不以删除有效心跳或放宽503断言掩盖。

## 2026-11-04 · T05存储与进程清理 [已解决]
