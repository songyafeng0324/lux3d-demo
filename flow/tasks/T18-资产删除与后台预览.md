# T18 个人资产删除、缩略图取景与后台上传预览

- **来源**：2026-11-10 用户四项反馈（原话摘要）：
  1. 个人生成的资产加删除；删除时同步清理藏宝阁上架、投稿入精品库、被收藏及摆在小屋里的等所有关联；删除需二次确认；按钮放在改名后面。
  2. 花草丛缩略图放大，所有藏品缩略图主体不要太小。
  3. 管理员上传模型时右侧出 3D 预览。
  4. 后台浏览资产页的“风险删除”改为“删除”。
- **状态**：实现与本机验证完成；浏览器回归（`test:t08` 含后台按钮改名）与跨模型评审在提交前跑。

## 做法
- **删除**：新增 `DELETE /api/v1/assets/:id`（本人、CSRF、幂等键），与后台删除共用 `riskDelete` 级联：清所有小屋摆放（推进版本）、所有收藏、待审投稿与精品库候选、所在展位（发布新展陈）、文件进清理队列；资产留最小墓碑。回执多带 `ownRoom`，打开着的小屋页据此衔接草稿版本。生成任务列表对已删资产给 `assetDeleted:true`、`assetId:null`。
- **二次确认**：卡片上改名笔后面加删除图标；第一次点击只在卡片内展开确认块（说明会撤下的范围），点「确认删除」才发请求；Esc / 取消收起。
- **缩略图**：`framePreview(model, camera, fill)` 按包围盒八角点的投影求最近距离，使主体沿约束轴占画面 88%（`THUMBNAIL_FILL`），扁平的花草丛、细长的长凳都不再缩成一小团。交互预览仍保留原远景便于旋转。
- **后台预览**：选择 GLB 后右侧即在浏览器本地解析预览（同样禁止外部资源），上传后服务器照常校验与渲染检查。
- **改名**：后台按钮与确认标题改为“删除…”“确认删除「…」？”，投稿相关的“已按风险规则删除”同步改为“已删除”。
