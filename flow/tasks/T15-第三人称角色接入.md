# T15 · 第三人称角色接入

- **背景**：六个带 `Idle` 和 `Run` 动画的角色 GLB 已交付（见 [角色目录](../../assets/characters/)），但藏宝阁和小屋仍是纯第一人称。源 GLB 每个 15～20MB，其中约 6MB 是没被引用的数据，贴图为 2048 PNG，不适合直接在场景里加载。
- **目标**：按 [2026-11-09 用户确认](../../docs/product/2026-11-09-第三人称角色接入.md)，在藏宝阁和小屋的参观、分享页提供可选角色的第三人称视角，`V` 键可切回第一人称。
- **输入**：六角色源 GLB；`apps/web/src/game/engine.ts`、`navigation.ts`；`apps/web/src/room/engine.ts`、`navigation.ts`；T10/T07 验证脚本。
- **实施**：
  1. `scripts/build-characters.mjs` 生成运行版 GLB：只保留被引用的数据，贴图转为 1024 JPEG（材质为 OPAQUE）；结果和 manifest 输出到 `assets/characters/runtime/`。
  2. 跟随镜头的遮挡计算写成纯函数，复用导航碰撞体，并加上楼板和屋顶的天花面；不用渲染网格做射线检测。
  3. 角色负责统一身高、脚底贴地、朝移动方向转身、`Idle` 与 `Run` 淡入淡出，并加脚下的圆形软阴影（静态阴影贴图不逐帧更新）。
  4. 两个场景引擎接入：默认第三人称，按 `V` 切换；`E` 选展台改为从角色视点射线；镜头离得太近时隐藏角色。
  5. 菜单和参观栏加角色与视角设置，偏好存在 localStorage，读写失败时退回默认值。
- **产出**：上述代码与脚本；单元测试 `tests/t15-third-person.test.mjs`；本机验证 `docs/validation/T15第三人称验证.md`。
- **验收标准**：`npm run build`、`npm test` 和 `npm run test:t10` 通过。在 Mac Chrome 中，藏宝阁一、二层与楼梯、小屋室内外和分享页里，六个角色都能加载、跑动、待机和转身；镜头贴墙、在楼板下或屋顶下都不穿模；`V` 切换正常，刷新后保留选择；`E` 查看展品正常；帧率与第一人称相近。另由一个模型独立复核。
- **追加（同日用户反馈）**：三个场景右上角统一放「角色」按钮，快捷键 `C`；选角框有缩略图和名称，点一下立即切换并关闭；三处操作提示统一；小屋参观支持 `Shift` 快走。组件为 `apps/web/src/game/CharacterPicker.tsx`，缩略图脚本为 `scripts/render-character-thumbs.mjs`。
- **状态**：完成（本机验证与独立评审通过，见 [T15 验证](../../docs/validation/T15第三人称验证.md)）
