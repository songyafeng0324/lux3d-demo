# T13 · 展品收藏与背包改版

**状态**　2026-11-07 用户确认实施，本机验收及独立复核完成。

## 目标与现状

参观者在藏宝阁按 `E` 看见喜欢的展品，可以收进背包，随后在同一份藏品清单里预览并摆进小屋。现有展品详情只能看，背包点卡片会进入包含改名和简介的详情，小屋也只允许摆放本人生成的模型和官方家具。本轮影响 F04、F05、F06、F09、F10 和 F13。

## 用户确认规则

1. **收藏范围**　用户投稿和官方馆藏都能收藏，官方展品署名「官方馆藏」。
2. **名称、昵称与撤展**　每次读取收藏时取候选当前获审公共名称和作者账号的当前昵称。普通撤展后，已收藏的模型仍可预览和摆放，停留在旧页面的用户不能新收。管理员风险删除清理所有背包和小屋引用。
3. **取消收藏**　取消时同一事务移除本人收藏和小屋中的全部对应摆放。分享刷新后显示新布局，旧凭证失去该模型的读取权限。重新收藏可重新摆放。

收藏按账号保存，添加不消耗生成次数。收藏者只获得预览和摆放权限。界面和接口分别限制改名与投稿，生成原图继续按原有私有权限处理。

## 实施顺序

1. **产品和数据契约**　将确认的范围、撤展、显示及分享规则记入产品增量与数据契约。为账号保存指向源模型的收藏关系，同一账号与源模型唯一。复用现有 GLB 和几何描述，保留历史资产与布局。收藏身份和权限独立于源模型所有权。
2. **服务端**　新增按展品收藏、收藏列表和取消收藏。新增收藏时核对登录、详情对应的展品凭证、源模型仍在展和模型可用状态，在同一事务内去重，并与撤展及风险删除按现有锁序协调。普通撤展后已成功的收藏仍可查询确认，风险删除后不能凭旧回执恢复。为收藏者开放对应 GLB 读取和小屋保存，分享按已有只读快照及当前收藏权限鉴权。取消收藏及风险删除与房间保存协同推进布局版本。自有资产支持名称单独保存，改名与投稿维持所有者校验。
3. **前端**　接通展品名称后的收藏按钮、成功和重试状态。改造背包为两类列表、卡片笔头和左侧预览，收藏缩略图复用模型缩略图流程。小屋物品库接入两类藏品。保持键盘可操作，切换卡片、账号或关闭浮层时释放旧预览，忽略迟到的请求结果。
4. **Mac 本机验收**　运行构建及受影响的自动化检查。独立 PostgreSQL 验证重试去重、其他账号越权、原图隔离、收藏与撤展或风险删除竞争，以及已有布局兼容。Chrome 双账号验证 `E` 收藏、分栏、改名与左侧 3D 预览、摆放保存、分享和风险删除。复用已有模型与隔离数据，完成独立代码复核并记录证据。
