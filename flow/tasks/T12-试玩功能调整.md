- **影响范围**　账号、个人资产、额度、小屋、只读分享、投稿与藏宝阁导航。

1. 注册和登录表单给出中文校验提示。登录、注册及注册确认密码可独立显隐。两处账号抽屉及后台登录使用同一密码输入组件。
2. 把默认每日生成额度调为 10。前台、后台、实际扣额一致，保留当天覆盖值、已用次数、北京时间日界、原日返还和单个在途任务约束。补建已有可登录管理员的小屋及第 0 版空布局，新管理员在创建账号的事务内同步建屋。

4. 藏宝阁、小屋和只读分享支持空格跳。藏宝阁二楼可主动越过中庭栏杆落到一楼，平地走路仍受栏杆约束。小屋参观与分享以泥土边缘为行走边界，处理室内外高差，按家具及个人模型当前变换生成碰撞盒。前后端共用正式小屋摆放范围，旧布局坐标继续有效。
5. 在 Mac 跑构建、受影响的单元、隔离 PG 和 Chrome 回归，复用已有模型或隔离 fixture 验证，记录结果并由另一模型复核。
