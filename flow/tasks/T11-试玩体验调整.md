# T11 · 试玩体验调整

- **状态**　2026-11-06 改版及布景返修均已完成，本机验证和独立复核通过。
- **目标**　让公共藏宝阁专注参观，让生成、管理与摆放藏品集中在个人小屋。按参考图扩大展品预览，并改善小屋外观及物品识别。
- **依据**　2026-11-06 用户的五项试玩反馈及展品弹窗标注图。沿用 MVP 的 F01～F06、F09、F10，涉及相关入口和显示方式。

## 已核对的现状

- **Lux3D**　服务端先读 `LUX3D_CN_API_KEY`，为空则读 `LUX3D_CREDENTIALS_FILE` 指定的文件，默认文件是 `~/.config/lux3d/credentials.json`，键名是 `apiKeys.cn`。本机此次解析命中默认文件，文件权限为 `0600`。Worker 用服务端凭证完成上传、创建和查询，浏览器访问本站 API。当前本机健康检查显示 `generationReady: true`。比对了工作区受跟踪文件和当前 Git 提交，均未发现该密钥的字面值。此次只检查状态，未提交生成任务。实现见 [凭证读取](../../packages/domain/src/credentials.ts)、[生成 Worker](../../packages/domain/src/generation.ts)。
- **本地工作台**　`/workbench` 只显示服务状态和导航，正式业务流程未使用该页面。T04 实验页有入口链接，部分浏览器回归用它做健康页检查或切换页面。删除时一并迁移这些引用，服务诊断继续查 `/api/v1/health/ready`。实现见 [前端入口](../../apps/web/src/App.tsx)。
- **图源**　个人生成资产已保存原图引用 `originalImageId`，可以复用登录态文件接口。只有 GLB 的家具或老资产需要另外生成静态图片。现有交互式预览在打开时渲染模型，不能直接当列表图片使用。

## 实施范围

1. **放大 E 展品详情（F09，AC37～38）**。按标注图估算，桌面弹窗约占视口 97% 宽、83% 高，上下留出 HUD 区域。正文左侧约 3/4 给可旋转、缩放的 3D 预览，右侧约 1/4 显示藏品资料、收藏方和署名。右栏独立滚动，窄屏改上下排列。空展位继续显示简短提示。检查长文、小窗口、加载失败和关闭后恢复参观。
2. **迁移入口并删除工作台（F01～F06）**。公共藏宝阁右上角只留「菜单」，移除首页背包按钮、B 快捷键及操作说明中的对应提示。菜单放「账号设置」，未登录可登录或注册，已登录可改昵称、改密码和退出。个人小屋提供「背包」入口，承接图片生成、额度、任务、藏品预览与编辑、投稿与撤回。背包和物品库在本页切换，登录后就地进入小屋，藏品入包后可在同一页刷新并摆放。删除工作台页面和菜单项，更新 T04 链接、仍执行的回归脚本和运行说明。旧的首页背包深链接跳转到小屋背包。
3. **初版小屋外观（F05、F10）**。保持明亮，把地面调为浅灰。以低饱和蓝天、淡云和薄雾拉开天际层次，在建筑外围点缀草丛与花簇。编辑、屋内参观和分享采用同一套环境。花草放在摆放和行走区域外，验证远近两个视角及低角度参观，保持现有保存与分享的场景契约。
4. **用静态缩略图识别藏品（F04～F05）**。优先复用上传原图，背包、物品库和已摆放列表共用同一张图。无原图的模型用统一视角生成一次静态预览图并缓存，加载失败时显示可辨认的占位，点击后仍可打开交互式 3D 预览或执行该列表原有的摆放操作。同源摆放副本共用缩略图，仍能单独选中、定位和移除。缩略图按需加载，个人图沿用本人权限，分享页只展示当前只读场景。
5. **在用户 Mac 验证**。检查桌面弹窗尺寸和比例、长资料可滚动、菜单登录与设置、小屋生成入口到摆放、投稿、刷新恢复、无痕分享权限，核对带原图和无原图两类资产。复用现有模型和隔离用例验证入口迁移，比较增加天空和花草前后的场景帧率，按改动范围运行构建及相关回归。

## 2026-11-06 · 布景返修

用户实玩反馈小屋与藏宝阁相比偏灰、过亮，屋内地砖与外部地面缺少区别，天空需能看清蓝天和白云，并要求两处场景都出现物体投影。此反馈覆盖初版小屋亮度及地面选色。

1. 以藏宝阁内的木色和明暗层次作对照，降低小屋曝光和环境补光。室内用较深青灰铺石，室外以带绿色植被的灰褐地面和石径分层，蓝天与白云在默认参观和布置视角均可辨认。
2. 小屋加可动态刷新的方向光阴影，建筑、家具和藏品参与投影。检查藏宝阁现有阴影在室内的实际效果，补充能照到室内展台和地面的阴影光源。
3. 在 Mac Chrome 同机位对照明暗及天空、地面，实际开关阴影比对像素，检查小屋挪动和切换视角时阴影更新、藏宝阁展品就位后阴影刷新，并复测已有导航及只读分享。
