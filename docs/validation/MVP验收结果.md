## 负载、主场景与恢复

- **十会话**。十个不同用户、登录 cookie 和房间各 20 轮；640 次 HTTP 请求、200 次保存，0 错误。每个会话最终核对自己的房间 ID、版本、名称和摆放。最后一轮登录 P95 507.70 ms，背包 1.74 ms，展陈 3.47 ms，房间读取 4.07 ms，保存 9.03 ms。保存计时为 API 往返，浏览器防抖单列在场景验收。[负载原始结果](evidence/t09/load.json)
- **真实主场景**。真实模型文件 9,030,232 字节、48,204 三角面。本次正式房间版本 62、10 件摆放，展陈版本 3、展位 2；报告采用实测值。Chrome 全屏走完二层往返约 55 秒，入口/二层 P95 帧间隔为 16.8/16.7 ms。正式展品从导航到载入约 0.85 秒（含入场点击）。[正式链路](evidence/t09/main.json) · [实走](evidence/t09/t10/browser-check.json)
- **正式小屋压力样本**。在 1500×1000、DPR 1.5 的 Chrome 与 Apple M5 Metal 渲染器上，用真实瓷瓶和家具混排 30/100 件，120 帧 P95 均为 16.7 ms，绘制约 73 万/242 万三角面。每档重新进入五次，GC 后 JS 堆分别从约 6.13/6.85 MB 到 5.92/6.70 MB。此为短时、重复样本测量。[小屋原始结果](evidence/t09/room-performance.json)
- **备份与恢复**。正式库生成私有备份，隔离恢复校验 dump、密钥摘要及 8 个文件，真实账号能登录恢复副本，并打开原有加密分享、编辑/保存/关闭及重开。恢复副本删除。另用只监听私有 Unix socket 的临时 PG 集群重启，原任务终态和模型 SHA 不变。[恢复检查](evidence/t09/restore.json) · [数据库重启](evidence/t09/pg-restart.json)
- **触屏提示**。本轮补齐首页和小屋提示，Chrome 模拟触屏 390×844 验证可见，桌面分享页不显示提示。[触屏截图](evidence/t09/mobile-hint.png)
