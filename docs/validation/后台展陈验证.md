## 本机复验中发现并修复的问题

- 四路并发偶发撤回 500：服务端新增按 requestId 的错误日志后定位为 PG 死锁（40P01）。风险删除对同一申请行两次 UPDATE，第二次重做外键检查对申请人 users 行取 KEY SHARE，与申请人已 FOR UPDATE 锁住自身用户行、正在等资产锁的撤回请求互等。改为每行单次 UPDATE，并把会话复核锁改为 FOR NO KEY UPDATE；12 轮复验通过。
