## 3. 必需工程边界

- 生成受理重复点击/网络重发、受理事务回滚、两个请求竞争最后一次额度、跨日单任务限制；午夜前后调额/返还。
- create响应丢失、dispatch开始后worker被杀、查询失败不等于任务失败；旧fence返回不能入包；落存成功但DB失败、渲染失败、迟到结果、备份恢复后禁止再create。
- 保存乱序/响应丢失/双标签页、拖动后立即离开/断网；回执不得覆盖后续编辑；不截断大布局。
- pending批准与新投稿/撤回竞争；跨表有效占用；批准后个人改昵称/资料不影响公共快照。
- 槽位交换不被中间唯一约束误拒绝；旧参观页在普通撤展后仍可加载其获准资源，不能枚举历史版。
- 分享关闭/重开原链接；旧grant epoch失效，新进入拒绝或重建资格；已加载画面允许保留，新文件读取不得绕过权限。
- 删除与旧保存/审核/展位发布竞争，不能复活；其他模型保留；物理清理失败仍不能新读被删文件。
- 路径穿越/软链、伪造归属/角色/assetID、CSRF、错误响应不泄露凭证；服务端接口直接访问与浏览器一致。
- 重启API/worker/PG、Mac睡眠唤醒恢复原任务；备份到隔离目录恢复，DB引用和文件hash一致。

补充必测：同键同时提交生成只扣一次且得到同task；同键保存只进一版且回执一致。后台导入崩溃/重放不得重复发布；原图归属、管理范围、Range重新鉴权和no-store策略验证。旧worker迟到ID仍可留对账证据；备份后新增提交也须对账，未核实的恢复库不能create。

## 4. 性能测量与收敛

T04先用真实代表样本记录纹理体积、三角面、draw calls、摆放数、冷加载时间、主线程帧时间分位数、内存、保存延迟与10会话API错误/延迟；反复进出场景和预览观测内存回收。测试规模是样本，不变成产品件数上限。用户尚未给FPS/秒数目标，首次结果出来后列出可达范围和具体优化，记录确认后的门槛，不补写已经达标。

3D基础要求：编辑/参观输入互不争用；手机提示；错误/进度反馈可读、键盘焦点可退出详情；加载失败和保存失败不会宣称成功。高复杂度无法运行时保留原布局并明确错误，不静默删除物品。
