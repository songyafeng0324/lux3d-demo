# 2026-11-07 · 展品收藏与背包改版

本次确认更新 F04、F05、F06、F09、F10 和 F13 的相关行为，实施见 [T13 任务卡](../../flow/tasks/T13-展品收藏与背包改版.md)。

- 藏宝阁按 `E` 打开展品详情，右侧标题旁可以将展品加入「我收藏的」。用户投稿和官方馆藏均支持收藏。每账号每模型一条收藏，已拥有的生成模型归入「我生成的」。收藏不计入生成额度。
- 「我生成的」在卡片名称旁用笔头改名。两类藏品点开时保留右侧列表，在左边显示「名称（昵称）」和 3D 预览。个人简介从藏品页移除，投稿栏目继续填写公开简介及其他展陈资料。
- 收藏资料以数据库当前值为准。作品名称取当前获审的公共名称，昵称取作者账号当前昵称，官方展品统一显示「官方馆藏」。个人背包改名维护私人名称，已获审的公共名称由候选资料提供。收藏者可以预览、摆放或取消收藏。
- 两类藏品都可以摆进自己的小屋。通过小屋分享链接可只读参观已摆放的模型。普通撤展保留已有收藏与摆放，旧展品详情无法继续创建新收藏。取消收藏同时移除本人背包记录和小屋中的全部对应摆放。管理员风险删除清理所有账号对该模型的收藏与摆放。
