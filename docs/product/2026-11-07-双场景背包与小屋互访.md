# 双场景背包与小屋互访

2026-11-07 用户确认。实施与验收见 [T14 任务卡](../../flow/tasks/T14-双场景背包与小屋互访.md)。

- 藏宝阁和自己的小屋均可点「背包」或按 `B` 打开同一功能。选图按钮提示使用无背景或白底图片。生成任务沿用每账号一个未完成任务的规则。
- 藏宝阁展品详情将投稿人标为「作者：昵称」。展品详情、投稿审核和其他简介展示标明「简介：」。
- 自己的小屋第一人称预览、分享参观和回到入口均从正门外台阶的外沿内侧开始，面向正门。
- 登录后可在自己的小屋打开「逛一逛」。榜单纳入当前全部开启分享的小屋，包括此前开启的分享。榜单列出当前作者昵称、已保存小屋名、人气及访问链接，按人气降序，同分按作者注册先后排序。持分享链接可匿名参观。
- 分享页的赞构成小屋人气，初始为零。每个已登录的非房主访客对同一间小屋只可赞一次，提交后不可撤销。房间关闭分享后下榜，重开后带原有人气重新上榜。
