# 2026-11-06 · 试玩功能调整

本页记录 T12 用户确认的增量，对应事项优先于 MVP PRD。其余规则继续查阅 [PRD](藏宝阁与个人小屋-MVP-PRD-v2.0.md)。

| 对应范围 | 确认规则 |
|---|---|
| F01 账号 | 注册规则和密码确认使用中文提示。登录密码、注册密码及确认密码默认隐藏，可独立点击小眼睛查看。可登录的管理员也有自己的小屋。 |
| F02～F04 生成与个人藏品 | 「生成任务」提供上传、可用额度和任务记录。「藏品」只显示个人藏品、预览和个人资料编辑。北京时间每天默认 10 次，切换当天沿用已用次数和管理员已设置的当日额度。 |
| F06～F08 投稿与策展 | 在背包的「投稿」栏选个人藏品并提交公共资料。记录、撤回和重提都在此栏。通过审核的卡片使用青玉色边框和「已通过」角标，是否已安排公共展位由投稿状态单独说明。 |
| F05、F10 小屋布置与参观 | 正式小屋可摆放到灰褐泥土地边缘，主人参观和只读分享可以走到同一庭院边界。官方家具和个人藏品根据各自模型及摆放变换阻挡角色。 |
| F09、F10 第一人称 | 藏宝阁、小屋参观和只读分享均可按空格起跳。藏宝阁可以从二楼跳过中庭栏杆落到一楼，普通走路时栏杆继续阻挡。 |
