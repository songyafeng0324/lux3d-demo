# T04 · 场景与交互方案

2026-11-04。本方案由可运行样本验证，正式账号与PostgreSQL保存/分享由T07接入，公共策展由T08实现。入口 `/lab/t04`，不是完整MVP验收页。

## 固定古建与素材

采用木构柱梁、格栅、浅石台基、灰绿双坡起翘屋面，空间保持开放且无物理碰撞。编辑隐藏屋顶以便观察，参观恢复屋顶；隐藏的是固定建筑的编辑视图，不隐藏用户摆放记录。此方向来自PRD7.4，由本地程序制作，属于流程可用样本，不是考据复原或最终美术交付。

`apps/web/src/scene/assets.ts` 是壳体、长案、靠背椅、双门柜的来源。固定几何按材质合并，房屋壳体/展台不进入布局数组，家具模板与每次摆放分离。T03模型来自真实任务4639946，原始GLB只从私有服务器读取；没有新增生成，也没有将T03模型写入Web public或主业务库。

## 坐标与边界

`packages/contracts/src/scene.ts` 是前后端共用的算法和数值源，场景版本 `courtyard-v1`。单位米，Y向上，右手坐标；角度为Euler XYZ弧度，正的等比scale。底部中心为物品pivot，T03原始几何按最长边归一化为1；家具保持其实际米制尺寸。

屋内可用长方体为X[-6,6]、Y[0,4.8]、Z[-4.5,4.5]。八角点先等比缩放再EulerXYZ旋转再平移，全部在体积内才有效，epsilon=1e-6。共享约束覆盖NaN/Infinity、重复摆放ID、未知资产、非正scale和边界；不只检查物品原点。随机500组变换另与独立旋转参考对比，浏览器核对实际模型/家具几何包含于同一bounds。

物品允许相交、悬空和堆叠。拖动过程中用红色包围框提示越界，松开时恢复本次操作前的合法变换；服务端对提交完整再检查。没有数值输入、撤销重做或物理碰撞。件数没有硬上限，布局不会被截断。实验服务单次传输限制64MiB，超出明确413且未保存；正式超大布局分块需在T07根据实际规模设计，不能假装已实现。

## 编辑与自动保存

场景使用Three.js原生TransformControls：XYZ移动、XYZ旋转、缩放时将三轴统一为同一正值。相机OrbitControls在拖动物品时暂停。鼠标选中和房间列表均可定位被遮挡物品；移除仅移除该摆放，同源其他副本与模板保留。

房间名及已完成的物品操作500ms防抖，单队列提交整版布局。状态为读取中/读取失败/待保存/保存中/已保存/未获确认/校验拒绝/版本冲突。初次读取失败禁止编辑，不将空默认布局保存。网络或丢响应保留原Idempotency-Key与body重试；确定400/413/422拒绝清掉旧请求，有后续草稿就提交新草稿。回执只确认其editSequence，后续编辑仍待保存。API重启失效的实验编辑会话可以重建一次，并重发原请求。

保存状态更新不会重新应用相同布局，正在拖动的对象也隔离旧确认布局，避免回执到达导致物品回弹。多标签CAS冲突保留本地草稿，明确确认后才能载入服务端版本；不自动覆盖另一页。离开未确认编辑有浏览器提示。只有服务端确认版本可作为恢复或新访客读取的布局，符合B01。

## 参观与30展位

小屋与展厅第一人称视点高1.65m，移动2.6m/s、鼠标灵敏度0.002rad/px，WASD/方向键，场景点击可锁定鼠标，Esc释放，回入口同时清空按键。编辑、详情、输入框不处理走动按键。这些是本轮工程样本参数，来源是可操作样本，不是用户指定数值。

展厅24×28m，5列×6排固定30位，间距4m，台面1.2×1.2m，高1.04m。真实模型最长边统一1.15m，底部中心对齐台面；展示没有手动变换。样本30位重复同一真实模型以测试负载，不代表发布30个候选或绕过正式同候选唯一规则。

E目标为相机中心射线最先命中的有效展位，命中距离≤2.8m；射线最先命中避免同时提示多个。详情打开清空走动并释放指针，独立模型预览允许旋转/缩放，Esc或关闭后继续参观。小屋分享不显示E提示、详情、模型下载或未摆入的背包。

## 验证服务与快照范围

`apps/api/src/t04.ts` 只在显式 `AHOLO_T04_LAB=1` 且API绑定127.0.0.1启用。`npm run dev`启用实验入口；打包运行默认关闭。主库不写实验数据，文件状态在私有 `Application Support/aholo-lux3d/t04/`；单进程队列、原子rename+fsync、版本CAS和回执同保存。它不能替代正式PG多进程事务或用户鉴权。

本地编辑入口POSTsession取得内存editor capability，owner读取及写入均需独立头；访客只获快照grant，省略grant不能退回owner。实验只允许实际本地监听Host/Origin与Vite代理；任一本机开发者仍可申请实验会话，这不是正式登录权限。

稳定分享token用于新进入/刷新签发最新确认版本的grant；已加载页面及旧grant保持旧普通布局。关闭分享推进epoch，旧grant不能新读文件；重开沿用稳定入口token并新发grant。风险删除仅发生在独立实验状态，清对应活动摆放并拒绝新文件读取，已加载画面不推送清空；T03原文件不删除，其他家具保持。正式稳定token加密、账号权限、PG删除事务仍交T07/T08。

## 资源与性能策略

同源模型克隆共享geometry/material/texture，移除摆放不释放其他副本的资源；整个场景销毁统一释放，ImageBitmap显式close。独立详情renderer在关闭时停止循环、解除监听、dispose并丢失其WebGL上下文。实验记录GPU对象计数、上下文回收和GC后的有限次堆数据，不以这些指标宣称无限运行零泄漏。

页面按路由懒加载场景代码，静态壳体按材质合并，不删布局记录，不以固定件数限制或降模型面数伪造结果。实测设备、DPR、可见窗口、模型三角面、纹理与1/30/100/300件、30展位、10会话结果见 [验证记录](../validation/场景交互验证.md)。
