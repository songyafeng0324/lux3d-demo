## 需求流转
1. 阅读 PRD 和宪章，区分既有规则与未决事项。
2. 需求变更写清影响的 Fxx/ACxx、原因和验收变化；已获授权则落实，存在业务取舍时交用户决定。
3. 先更新 `flow/plan.md`，再建 `flow/tasks/Txx-描述.md`，内容产物归本目录。
4. 完成实现与相称验证后，独立评审结论落 `reviews/`，进展和下一步写回 `flow/进展.md` 顶部。
